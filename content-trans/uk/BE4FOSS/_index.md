У 2020 році Umweltbundesamt («Німецька агенція з навколишнього середовища») розповсюдила критерії надання екосертифікації міткою Blauer Engel для програмного забезпечення для робочих станцій. Серед категорій сертифікації енергоефективність, подовження потенційного строку експлуатації обладнання та автономність користувача… і усе це чудово компонується із вільним і відкритим програмним забезпеченням.

The BE4FOSS project advances eco-certification for resource efficient software in the FOSS community. Obtaining the Blauer Engel label occurs in 3 steps: (1) MEASURE, (2) ANALYZE, and (3) CERTIFY.

1. MEASURE in dedicated labs, such as at KDAB Berlin
1. ANALYZE using statistical tools such as OSCAR (Open source Software Consumption Analysis in R)
1. CERTIFY by submitting the report on the fulfillment of the Blauer Engel criteria

Серед переваг, які надає екомітка, такі:

- Визначення досягнення високих стандартів нешкідливого для середовища дизайну програмного забезпечення
- Показ переваг вільного програмного забезпечення у порівнянні із альтернативами
- Збільшення запиту щодо впровадження серед споживачів
- Просування прозорості у екологічному аспекті програмного забезпечення
