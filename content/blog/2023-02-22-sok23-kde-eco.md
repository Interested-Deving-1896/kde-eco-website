#### What I Will Be Working On

In this project, we will set up Selenium using the Selenium AT-SPI and replicate an existing unit test written with KdeEcoTest to test GCompris. By measuring then comparing the energy needed by KdeEcoTest and Selenium we will be able to decide if and how we can use Selenium to run energy consumption scenarios. Selenium AT-SPI for QT is still in an early stage but it is relevant to KDE as a unit testing tool and could become a great tool for energy consumption measurement.

I will also write a guide for installation of selenium-webdriver-at-spi and GCompris application scripts using selenium-webdriver-at-spi. This guide aim is to provide help to developers to create their own kde app tests, as system testing tool or power consumption measurement tool.

#### Motivation Behind Working On The KDE Eco Project

I have a strong interest in Ecology and want to develop technique that will reduce the impact of new technology on the planet. Currently, we are using KdeEcoTest for GCompris power consumption measurement. In this project, we will write unit tests of GCompris using Selenium.  Using Selenium we can get elements using name and many different features, which provides much more flexibility than what KdeEcoTest is able to do today.Selenium also works with Wayland, which is not the case of KdeEcoTest.

#### What I Have Done & Will Be Doing In The Coming Weeks

For past 2 weeks, I was understanding the KdeEcoTest and exploring selenium-webdriver-at and writing the unit tests scripts using selenium-webdriver-at-spi to replicate KdeEcoTest behavior.

During the first week, I have work on the setup of GCompris application and explored the code activities. I then work KdeTestEcoCreator script and understood how the code present in [``FEEP``](https://invent.kde.org/teams/eco/feep/-/tree/master/tools) repository is working.

I then explored the [``selenium-webdriver-at-spi``](https://invent.kde.org/sdk/selenium-webdriver-at-spi) and wrote an installation guide and guide can be found [here](https://invent.kde.org/nitintejuja/feep/-/blob/selenium/tools/KdeEcoTestSelenium/setup.txt). You can already use this to install your own selenium accessibility server to test your own KDE applications!

After these setups, I have been learning how to write unit scripts and have written my first selelium python script which simply opens GCompris.
